# Segurança

Se encontrar um problema de segurança neste projeto, avise em particular pelo GitHub, em
**Security > Report a vulnerability** deste repositório, e não numa issue pública.

Isso inclui uma pergunta que faça a conferência deixar passar uma resposta sem citação real da lei.

O projeto não tem dependências. Só chama a rede quando alguém roda a avaliação com o modelo de verdade, com `--confirmo-custo`, e aí usa a chave ou o login do gcloud de quem roda. Nenhuma chave fica no repositório.
